# Student Grade Calculator

## Introduction
A simple Java program that calculates a student's total marks, percentage, and grade.

## Features
- Accepts student name.
- Takes marks in three subjects.
- Calculates total marks.
- Calculates percentage.
- Displays the student's grade.

## Technologies Used
- Java
- Scanner Class

## Sample Output
- Total Marks: 255
- Percentage: 85.0
- Grade: A

## How to Run
1. Open StudentGradeCalculator.java.
2. Run it using a Java compiler.
3. Enter the student name and marks.

## Project Type
Beginner Java Practice Project.
